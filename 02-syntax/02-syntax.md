## 🔍 Ключевые концепции

1. **Модель памяти срезов (`3-array_slice_map`):**
   - Срез — это заголовок (`SliceHeader`) из 3 полей: указатель на массив, длина (`len`), вместимость (`cap`).
   - Функция `append` перевыделяет базовый массив в куче с коэффициентом роста, если `len == cap`.

2. **Словари (`map`):**
   - Хэш-таблица на основе бакетов (buckets). Чтение несуществующего ключа возвращает zero-value соответствующего типа.
   - Проверка наличия ключа через идиому «comma-ok»: `val, ok := m[key]`.

3. **Указатели и получатели методов (`5-methods_ifaces`):**
   - `func (s MyStruct) Method()` (Value receiver) — метод получает копию структуры.
   - `func (s *MyStruct) Method()` (Pointer receiver) — метод может мутировать исходную структуру, избегает копирования больших структур.

4. **Обработка ошибок в Go (`6-errors`):**
   - В Go нет исключений (`try-catch`), ошибки возвращаются как обычные значения последним аргументом кортежа: `func Foo() (Result, error)`.
