# Домашнее задание №5: Ввод и вывод в Go (Персистентность поисковых данных)

В данном домашнем задании реализована новая итерация поискового робота **GoSearch** с сохранением отсканированных веб-документов в файл и их последующей загрузкой при старте приложения без повторного обращения к сети.

## Выполненные задачи:

### Задача №1: Механизм записи данных в файл (`io.Writer`)
- Разработан пакет `pkg/storage` с функцией `Store(w io.Writer, docs []crawler.Document) error`.
- Функция принимает интерфейс `io.Writer`, что позволяет записывать данные в файл (`*os.File`), сетевой сокет, HTTP-ответ или `bytes.Buffer` для тестов.
- Данные сериализуются в формате JSON с форматированием `json.NewEncoder(w)`.
- Также реализована поддержка бинарного формата `StoreGOB(w io.Writer, docs []crawler.Document) error` для компактного Go-to-Go сохранения.

### Задача №2: Загрузка данных из файла (`io.Reader`)
- Разработана функция `storage.Load(r io.Reader) ([]crawler.Document, error)`.
- При старте `cmd/gosearch/main.go` проверяется наличие кэш-файла `docs.json` (или файла, указанного через флаг `-file`).
- Если файл существует:
  - Программа открывает файл `os.Open()` и передает его как `io.Reader` в `storage.Load()`.
  - Сканирование сайтов по сети **полностью пропускается**, экономя время и сетевой трафик.
- Если файла нет:
  - Выполняется сканирование сайтов роботом `spider` (или `membot`).
  - Результаты сканирования сохраняются в файл через `storage.Store()`.

## Запуск и использование:

```bash
# 1. Первый запуск (файла docs.json нет -> сканирует сеть и сохраняет файл docs.json):
go run ./cmd/gosearch -s "golang"

# 2. Второй запуск (файл docs.json найден -> загружает данные из файла без сканирования сети):
go run ./cmd/gosearch -s "golang"

# 3. Принудительное пересканирование с обновлением файла:
go run ./cmd/gosearch -rescan -s "golang"

# 4. Использование автономного membot и кастомного файла:
go run ./cmd/gosearch -mem -file my_cache.json -s "go"

# 5. Запуск интерактивного режима:
go run ./cmd/gosearch -file docs.json
```
