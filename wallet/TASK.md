# Техническое задание: Сервис управления кошельками (Wallet Service)

## Описание задачи

Необходимо написать веб-приложение, которое по REST принимает запрос на изменение баланса кошелька вида:

### 1. Изменение баланса кошелька
**POST** `api/v1/wallet`

```json
{
  "valletId": "UUID",
  "operationType": "DEPOSIT or WITHDRAW",
  "amount": 1000
}
```

После получения запроса выполняется логика по изменению счета в базе данных.

---

### 2. Получение баланса кошелька
Также есть возможность получить баланс кошелька:

**GET** `api/v1/wallets/{WALLET_UUID}`

---

## Стек технологий
* **Golang**
* **PostgreSQL**
* **Docker & Docker Compose**

---

## Ключевые требования к реализации

1. **Работа в конкурентной среде (High Concurrency):**
   * Обратите особое внимание проблемам при работе в конкурентной среде (**1000 RPS по одному кошельку**).
   * **Ни один запрос не должен быть не обработан (50Х error).**
2. **Контейнеризация:**
   * Приложение должно запускаться в Docker-контейнере.
   * База данных также запускается в Docker-контейнере.
   * Вся система должна подниматься с помощью `docker-compose`.
3. **Тестирование:**
   * Необходимо покрыть приложение тестами (юнит-тесты и интеграционные стресс-тесты на конкурентность).
4. **Управление конфигурацией:**
   * Переменные окружения должны считываться из файла `config.env`.
5. **Публикация в Git:**
   * Решенное задание залить на GitHub, предоставить ссылку.
6. **Автономность принятия решений:**
   * Все возникающие вопросы по заданию решать самостоятельно, по своему усмотрению.
7. **Изоляция:**
   * Для решения этого задания необходимо создать отдельную директорию (`wallet`).
