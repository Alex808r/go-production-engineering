# Домашнее задание №4: Двусвязный список со сторожевым элементом

Реализация циклического двусвязного списка со сторожевым элементом (`sentinel node`) в соответствии с Занятием №4 курса «Современная разработка на Go».

---

## 🎯 Что реализовано:

1. **Пакет `pkg/list`**:
   - `List` со сторожевым элементом `root`: устраняет необходимость проверки краевых условий `head == nil`.
   - `Pop() *List`: удаление первого значащего элемента списка с поддержкой fluent-интерфейса (цепочечных вызовов).
   - `Reverse() *List`: разворот связей `next` и `prev` на месте (*in-place*) за время $O(N)$ и память $O(1)$.
   - `Push(e)`: вставка в начало списка с сохранением корректного указателя хвоста (`root.prev`).
   - `String()`: строковое представление списка.
