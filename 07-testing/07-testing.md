# 07-testing — Тестирование в Go: от Unit-тестов до бенчмарков

В данной директории подробно разбираются все аспекты тестирования на языке Go: табличные тесты, `TestMain`, тестирование HTTP-хэндлеров через `httptest`, подход TDD, мокирование и профилирование бенчмарков.

---

## 📋 Структура каталога

```text
07-testing/
├── 1-simple/        # Простые модульные тесты функции (t.Error, t.Fatal)
├── 2-testmain/      # Инициализация и освобождение общих ресурсов пакета через TestMain(m *testing.M)
├── 3-table/         # Идиоматичные табличные тесты (Table-driven tests) со структурой кейсов
├── 4-refactoring/   # Рефакторинг кода и безопасный пропуск тестов (t.Skip) при сетевых сбоях
├── 5-db/            # Тестирование кода работы с базой данных через интерфейсы
├── 6-handler/       # Тестирование HTTP-обработчиков (net/http/httptest, NewRecorder, NewRequest)
├── 7-tdd/           # Разработка через тестирование (Test-Driven Development: Red-Green-Refactor)
├── 8-benchmarks/    # Бенчмарки производительности (b.N, b.ResetTimer, b.ReportAllocs)
└── flags/           # Пользовательские флаги командной строки для тестового запуска
```

## 🔍 Ключевые концепции

1. **Табличные тесты (`3-table`):**
   - Общепринятый стандарт тестирования в сообществе Go:
     ```go
     tests := []struct {
         name string
         input int
         want  int
     }{ ... }
     for _, tt := range tests {
         t.Run(tt.name, func(t *testing.T) { ... })
     }
     ```

2. **`TestMain` (`2-testmain`):**
   - Управляет жизненным циклом тестов в пакете: инициализация тестовых БД, миграции и корректное закрытие соединений.
   - Завершается через `os.Exit(m.Run())`.

3. **Тестирование HTTP (`6-handler`):**
   - Использование пакета `net/http/httptest` позволяет проверять HTTP-эндпоинты без реального открытия сетевого порта на машине.

4. **Бенчмарки (`8-benchmarks`):**
   - Замеряют скорость (`ns/op`) и аллокации памяти (`B/op`, `allocs/op`).
   - Флаг `-benchmem` выводит подробную статистику работы сборщика мусора.

---

## 🚀 Запуск тестов и бенчмарков

```bash
# Запуск всех тестов пакета testing
go test -v ./07-testing/...

# Запуск тестов с покрытием кода
go test -cover ./07-testing/...

# Запуск бенчмарков с замером аллокаций памяти
go test -bench=. -benchmem ./07-testing/8-benchmarks
```
