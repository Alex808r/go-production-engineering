# docs-ai-rules

Перед применением прочитай [общие правила](../../../AGENTS.md).

1. Общие правила меняй в AGENTS.md, процедуры — в .agents/skills. Адаптеры не должны содержать расходящиеся копии.
2. Проектную документацию размещай в go-documentation/; не создавай произвольные Markdown-файлы в корне.
3. Пиши по прочитанному коду и реальным командам; отличай текущее поведение от предлагаемого. Используй относительные ссылки для новых документов.
4. Обновляй go-documentation/README.md при добавлении/переименовании разделов и гайдов. Существующие file:/// ссылки не ломай массовым переписыванием.
5. Проверь ссылки, якоря и fenced blocks; для диаграмм применяй mermaid-diagrams, для запрошенного форматирования таблиц — align-tables.
6. Не копируй локальную память, настройки пользователей, credentials или внутренние адреса из других проектов. Настройки модели и инструменты клиента не являются общими требованиями.
