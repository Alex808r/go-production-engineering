# mermaid-diagrams

Перед применением прочитай [общие правила](../../../AGENTS.md).

1. Прочитай файлы, которые объясняет диаграмма; не выдавай эскиз будущей архитектуры за существующую систему.
2. Выбери flowchart для зависимостей, sequenceDiagram для вызовов во времени, erDiagram для схемы данных, timeline для хронологии.
3. Подписи на русском, идентификаторы из кода сохраняй. Переносы в узлах — <br/>; заключай сложный текст в кавычки.
4. Один компонент/объект — один участник sequenceDiagram; собственный вызов показывай стрелкой к себе, балансируй activate/deactivate и блоки alt/loop.
5. Проверяй направление зависимостей, ошибки, транзакции и асинхронные границы. Используй компоненты, подтверждённые исходниками.
6. Обнови навигацию при добавлении раздела. Если Mermaid renderer недоступен, сообщи, что выполнена только структурная проверка.
7. Исторический путь go-documentation/mermaid-diagrams/SKILL.md ссылается на этот навык.
