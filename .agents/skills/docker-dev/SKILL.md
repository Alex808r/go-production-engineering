# docker-dev

Перед применением прочитай [общие правила](../../../AGENTS.md).

1. Читай Compose, Dockerfile, Makefile и конфигурацию конкретного сервиса до команд.
2. Без изменения состояния можно проверить docker compose config --quiet и ps из каталога сервиса, а также ограниченный фрагмент logs. Не печатай разрешённую конфигурацию с секретами.
3. Для wallet Makefile содержит docker-up, docker-down, docker-reset, docker-logs и docker-tools. docker-reset выполняет down -v и удаляет данные.
4. Запуск стека/инструментов — только по явной команде пользователя; разрешение на диагностику не означает пересоздание базы, удаление volumes или prune.
5. Для lynks учитывай build context родительского каталога и фактические порты/healthcheck из lynks/docker-compose.yml.
6. Если Docker недоступен, укажи это и продолжи независимые проверки. Не убивай процесс на занятом порту без поручения.
