# align-tables

Перед применением прочитай [общие правила](../../../AGENTS.md).

1. Запускай из корня: python3 scripts/agents/align_tables.py <файл.md> [другой.md]. Предварительная проверка: добавить --check.
2. Обрабатывай только порученные файлы; без аргументов скрипт не сканирует репозиторий. Форматирование не запускается скрытыми хуками после каждой правки.
3. Сохраняй содержимое ячеек, порядок строк, направление выравнивания и строки вне таблиц. Кодовые блоки, indented code и неоднозначные таблицы пропускай.
4. После выполнения проверь diff. Нестандартные escaped pipes/inline code разбирай вручную, если скрипт оставил их без изменения.
