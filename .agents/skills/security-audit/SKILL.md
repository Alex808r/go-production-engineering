# security-audit

Перед применением прочитай [общие правила](../../../AGENTS.md).

1. Определи scope, границу доверия и версии зависимостей в обоих модулях. Не сканируй чужую инфраструктуру.
2. Проверь валидацию HTTP-входа и лимиты, авторизацию, SSRF/redirect, SQL-параметры, path traversal, таймауты, утечки секретов и конкурентный доступ.
3. Для wallet проверь целостность денежных операций, блокировки и повторы по коду; не предполагай их корректность по названию сервиса.
4. Если govulncheck установлен, проверь его --help и запусти в каждом затронутом модуле. Не устанавливай и не обновляй зависимости без необходимости в порученной работе.
5. Отчёт: сценарий, влияние, доказательство в коде/результате инструмента, рекомендация и ограничения. Недоступный сканер не означает отсутствие уязвимостей.
6. Не копируй credentials в отчёт; не подавляй предупреждение и не меняй версии ради зелёного отчёта без анализа совместимости.
