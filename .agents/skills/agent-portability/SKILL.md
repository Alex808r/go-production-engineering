# agent-portability

Перед применением прочитай [общие правила](../../../AGENTS.md).

1. Общий источник: AGENTS.md и .agents/skills. Клиентские адаптеры должны только направлять к ним.
2. Проверь актуальную документацию клиента до изменения его config/hook/subagent формата. Не считай имена инструментов и поля permissions переносимыми.
3. Если клиент не обнаруживает Skills, явно прочитай нужный SKILL.md и ссылки из него.
4. Не копируй модели, личную память, MCP credentials, абсолютные пути или auto-approve из другого проекта. Отсутствие runtime-функции обозначай, а не имитируй её успех.
5. После изменения запускай python3 scripts/agents/check_setup.py; проверь относительные ссылки и адаптеры. Автозагрузка зависит от клиента и доверия к проекту: статическая проверка не заменяет запуск клиента.
