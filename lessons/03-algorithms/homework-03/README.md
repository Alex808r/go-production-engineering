# Домашнее задание №3: Быстрый поисковый индекс (Inverted Index & Binary Search)

Вторая итерация поискового движка GoSearch с использованием инвертированного индекса и бинарного поиска (Занятие №3 курса «Современная разработка на Go»).

---

## 🎯 Что реализовано:

1. **Пакет `pkg/index`**:
   - `Service` — структура инвертированного индекса (`map[string][]int`), сопоставляющая каждое слово из заголовков страниц со срезом идентификаторов документов (`ID`).
   - `Add(docs)` — построение индекса с нормализацией слов (приведение к нижнему регистру, очистка от пунктуации и дедупликация ID).
   - `Search(word)` — быстрый поиск за $O(1)$ по хэш-таблице индекса.
   - `BinarySearch(docs, targetID)` — логарифмический поиск документа по его номеру в отсортированном массиве (`sort.Search`) за $O(\log N)$.

2. **Обновленный поисковый движок `cmd/gosearch`**:
   - Каждому документу присваивается уникальный номер `ID`.
   - Массив документов сортируется по `ID` с помощью `sort.Slice`.
   - При передаче флага `-s <слово>` поиск сначала выполняется по индексу, а затем каждый найденный документ извлекается из массива методом бинарного поиска.
