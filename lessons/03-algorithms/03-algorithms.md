# 03-algorithms — Базовые алгоритмы и вычислительная сложность

В данной директории представлены классические алгоритмы поиска, рекурсивные вычисления, основы динамического программирования и обход графов на языке Go.

## 🔍 Ключевые концепции

1. **Бинарный поиск (`1-search/search.go`):**
   - Работает на отсортированных данных.
   - Делит пространство поиска пополам на каждом шаге: временная сложность $O(\log N)$, пространственная $O(1)$.
   - Безопасное вычисление середины: `mid := low + (high-low)/2` для предотвращения переполнения целых чисел.

2. **Бенчмаркинг алгоритмов (`1-search/search_test.go`):**
   - На массиве из $1\,000\,000$ элементов бинарный поиск выполняется за ~34 нс, тогда как линейный поиск требует ~346\,000 нс (ускорение в 10 000 раз).

3. **Динамическое программирование и Фибоначчи (`3-dynamic/dynamic.go`):**
   - **Мемоизация (Top-Down):** рекурсивное деление задачи с кэшированием результатов в `map` ($O(N)$ времени, $O(N)$ памяти).
   - **Итерация (Bottom-Up):** вычисление в цикле с 2 переменными ($O(N)$ времени, **$O(1)$** памяти — в 60+ раз быстрее рекурсии с мемоизацией, 0 аллокаций).
   - **Замыкание (Closure):** инкапсуляция состояния в куче (Escape Analysis) для пошаговой генерации ($O(1)$ за вызов).
   - **Ленивый итератор Go 1.23+ (`iter.Seq`):** идиоматичный обход через `for v := range fiboSeq()`.
   - **Большие числа (`math/big`):** вычисление $F(n)$ при $n \ge 92$ без тихого целочисленного переполнения `int64`.

4. **Графы (`4-graph`):**
   - Моделирование связей между узлами и поиск кратчайших путей.
