# 05-io — Потоковый ввод-вывод, файлы, флаги и JSON

В данной директории изучаются интерфейсы потокового ввода-вывода стандартной библиотеки Go (`io.Reader`, `io.Writer`), буферизация (`bufio`), файловая система, разбор CLI-флагов и сериализация JSON.

## 🔍 Ключевые концепции

1. **Контракты `io.Reader` и `io.Writer`:**
   - Фундаментальные интерфейсы ввода-вывода в Go:
     ```go
     type Reader interface { Read(p []byte) (n int, err error) }
     type Writer interface { Write(p []byte) (n int, err error) }
     ```
   - Любой источник (файл, TCP-сокет, HTTP-ответ, буфер в памяти) работает единообразно через эти абстракции.

2. **Буферизация (`bufio`):**
   - Уменьшает количество системных вызовов за счет накопления данных во внутреннем буфере (по умолчанию 4 КБ).

3. **JSON и структуры данных (`7-json_serialize`):**
   - Управление именами полей и пропуском пустых значений через структурные теги: `` `json:"id,omitempty"` ``.
   - Использование потокового `json.NewDecoder(r)` vs загрузки всего слайса байт в память `json.Unmarshal(b, &v)`.

4. **Флаги командной строки (`6-flags`):**
   - Создание удобных CLI-интерфейсов с валидацией параметров.
