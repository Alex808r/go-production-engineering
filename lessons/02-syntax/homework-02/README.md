## Условие задачи

1. Создать приложение со стандартной структурой каталогов `cmd/` и `pkg/`.
2. Скопировать пакет `crawler` (включая реализации `spider` и `membot`).
3. Использовать пакет `crawler` для сканирования сайтов `https://go.dev` и `https://golang.org` на глубину 1.
4. Объединить результаты сканирования в один массив документов.
5. Реализовать консольный поиск по отсканированным документам по слову, задаваемому флагом командной строки `-s`.

## Структура проекта

```
homework-02/
├── cmd/
│   └── gosearch/
│       ├── main.go         # Точка входа, парсинг флагов (-s, -mem), вывод результатов
│       └── main_test.go    # Модульные тесты консольного поиска
└── pkg/
    └── crawler/
        ├── crawler.go      # Интерфейс Scanner и структура Document
        ├── membot/
        │   └── membot.go   # Локальный эмулятор сканирования для тестов
        └── spider/
            └── spider.go   # Сетевой веб-краулер на базе golang.org/x/net/html
```

## Реализация компонентов

- **Флаги командной строки**:
  - `-s <слово>`: подстрока для регистронезависимого поиска в URL и заголовках документов.
  - `-mem`: запуск с использованием легковесного эмулятора `membot` без обращения к внешней сети.
- **Объединение результатов**: срезы `[]crawler.Document` объединяются с помощью `append`.
- **Поиск**: функция `searchDocs(docs []crawler.Document, query string)` выполняет регистронезависимую фильтрацию и нумерацию совпадений.
